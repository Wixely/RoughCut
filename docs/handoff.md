## Current state

On 2026-09-21 external executables stopped depending on `PATH`. FFmpeg, FFprobe, yt-dlp and Deno resolve through one shared order in every host — explicit argument, then `ROUGHCUT_FFMPEG`/`ROUGHCUT_FFPROBE`/`ROUGHCUT_YTDLP`/`ROUGHCUT_DENO`, then a tools settings file (`ROUGHCUT_TOOLS`, or `roughcut.tools.json` beside the executable, or `%LOCALAPPDATA%\RoughCut\tools.json`), then `PATH`. `roughcut tools` prints what resolves, from where, and whether a configured path exists. The desktop previously ignored all four variables and the playback proxy builder always used `PATH`; both now use the shared settings. The whole suite passes with a stale 2018 FFmpeg still first on `PATH`. See the [development guide](development.md). Owner: Implementation agent.

On 2026-09-21 the desktop gained an end-user entry point. Started with no arguments it opens on a project launcher — recent projects, a video-URL field, **New from a local video…**, **Open a project…**, a drop target and a typed path — so the app no longer requires a command-line path, and projects can now be created from the window rather than only the CLI; `review <project.json>` still opens one directly. History is per-user state at `%LOCALAPPDATA%\RoughCut\recent-projects.json`, bounded to ten entries and never part of project JSON. **Browse for a project…** opens the real operating-system picker: CupriFace has no dialog and ships SDL2, so RoughCut calls `GetOpenFileNameW` on Windows and zenity/kdialog on Linux, on an STA thread owned by the RoughCut window. That dialog moves the process working directory, which RoughCut now restores. A WebM supplied with `review <project> <preview.webm>` now survives edits, undo and reload instead of being replaced by a validated rebuild that fails for that source, and its status says when it no longer shows the latest edits. VS Code launches were regrouped to 29 profiles in seven groups with **▶ RoughCut** first. See the [launcher evidence](evidence/2026-09-21-desktop-launcher.md). Owner: Implementation agent; next run the window interactively on a physical device.
