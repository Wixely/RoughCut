## Live local STT

Windows `System.Speech` generated a non-personal fixture by repeating “Rough Cut keeps speech processing local. Timed segments remain portable and reviewable.” twelve times. FFmpeg combined it with a synthetic test pattern into a 77.1-second Matroska source. The following commands prepared the verified model, created a project and transcribed it:

```powershell
dotnet run --project src/RoughCut.Speech.Cli -- model artifacts/models/ggml-base.en.bin
dotnet run --project src/RoughCut.Cli -- create artifacts/live-rc03/source.mkv artifacts/live-rc03/project.json
dotnet run --project src/RoughCut.Speech.Cli -- transcribe `
  artifacts/live-rc03/project.json source-1 1 artifacts/models/ggml-base.en.bin en 30
```

Observed: three sequential bounded chunks completed in 9.3 seconds for the final run, produced 25 non-empty timed segments spanning 0–76.080 seconds, advanced the project from revision 1 to 2, and wrote a content-addressed SRT. The project records provider `whisper.net`, model `base.en`, language `en`, chunk size 30 seconds and the exact source SHA-256. Representative recognition was “Roughcut keeps speech processing local.” and “Time segments remain portable and reviewable.”

The live run found two boundary cases now covered by the implementation: Whisper's last segment can extend slightly beyond its PCM chunk, and FFmpeg resampling can end two samples short. The provider clamps the segment to the supplied PCM boundary. The processor zero-pads only a shortfall of at most one millisecond and rejects larger, odd-sized or oversized PCM output.
