## Environment and versions

The live run used WSL2 Ubuntu 24.04, Python 3.12.3 and a CUDA-capable GPU. The isolated environment and 4.3 GiB model cache were outside the repository. The service bound only to `127.0.0.1` and loaded only `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`.

The initially resolved Transformers 5.17.0 failed while initializing the Qwen speech tokenizer because a Mimi configuration lacked `rope_theta`. Pinning 5.15.1 resolved the failure and the same model loaded successfully. SoX was absent and warned during startup; WAVE synthesis still completed through the wrapper's soundfile path.

## Live result

The service status reported English, the exact CustomVoice model and a loaded model. RoughCut CLI synthesized the neutral text `Replacement text` using built-in voice `aiden`, starting from project revision 3.

The first request included CUDA graph warmup and completed at the CLI in 2.74 seconds. The engine reported 1.08 seconds of model audio generated in 0.40 seconds after warmup (reported RTF 2.71). The service returned a 49,964-byte mono PCM signed-16-bit WAVE at 24 kHz. RoughCut validated and stored 1.040 seconds of audio, advanced the project to revision 4, and recorded `faster-qwen-tts-aio@0.1.0`, model, voice, language, text hash, audio hash and requested/actual durations.

Applying the preview to the 1.000-second speech interval returned the expected exact-duration rejection. No source media or generated audio is committed.

## Deterministic coverage and limits

The executable C# fixture covers status/model/language/load validation, bounded WAVE handling, caller cancellation, timeout translation, CLI synthesis and official-client MCP synthesis. The MCP contract exposes 23 tools. Managed and Windows x64 NativeAOT-CLI verification each passed 44 checks. The live run proves one WSL/CUDA configuration and one short English built-in-voice request. It does not establish subjective quality, other voices/languages, sustained throughput, server-side cancellation of in-flight GPU work, Windows-native Qwen execution, general Linux support, duration fitting or rendered replacement export.
