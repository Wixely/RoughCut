# RC-04 evidence-backed analysis evidence — 2026-09-19

- Platform: Windows x64
- Scope: provider-neutral analysis contracts, conservative policy, persistence, exact proposal application and CLI/MCP parity

## Fixtures and observed behavior

Synthetic labelled observations cover a high-certainty sponsorship removal, a low-certainty possible advertisement and retained main-topic content. Each observation references source-time transcript or frame evidence. No personal media or external inference provider is used.

The executable checks prove:

- `review` leaves both high- and low-certainty removal recommendations for review;
- `auto-high-certainty` approves only the high-certainty removal and retains the uncertain interval;
- explicit proposal IDs apply a reviewed removal without approving retain recommendations;
- exact half-open source intervals split clips while preserving material before and after the removal;
- overlapping selected ranges are structurally mergeable by the same planner;
- stale proposal revisions, missing evidence, invalid references and policy-tampered decisions are rejected;
- media fingerprints are checked before analysis persistence;
- timeline edits invalidate prior proposals;
- CLI analysis/save/apply and MCP analysis/review paths use the same application operations;
- an omitted MCP proposal list cannot apply a review-only decision.
